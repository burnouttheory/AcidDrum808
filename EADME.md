# Acid Drum 808

**Analog Drum Machine & Step Sequencer — VST3**

**Version 1.5.12 | Windows 64-bit**

Acid Drum 808 is a VST3 drum synthesizer inspired by classic analog rhythm machines, featuring a 16-step sequencer, MIDI integration, sound shaping and automation.

## Main Features

- 11 analog-style drum instruments
- 32 patterns across 4 banks
- 1–16 step sequencing
- Individual instrument sound controls
- Three-band compression per instrument
- Accent and shuffle controls
- MIDI import and export
- FL Studio synchronization
- Native VST3 parameter automation
- Real-time visual knob automation
- 250 Factory presets organized by musical style
- Factory and User preset management
- Project state and preset restoration
- French and English interface
- Custom VST3 installation directory
- GitHub update-checking support

## Installation

Download the Windows installer from the latest GitHub Release.

Close your DAW before installation. Run the installer, select your VST3 directory, and rescan plugins if necessary.

## Presets

Factory presets are organized by musical genre. Personal presets can be saved in the User folder.

Existing user presets are preserved during updates.

## Documentation

French and English user guides are provided in this repository.

## Compatibility

- Windows 64-bit
- VST3-compatible DAW
- Developed and tested with FL Studio
